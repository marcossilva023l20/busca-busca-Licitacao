RADAR·LICITAÇÕES

Ferramenta de inteligência de mercado para fornecedores do setor público. Prazo é dinheiro: monitore o fim do recebimento de propostas e chegue antes.

Fonte de dados

Dados públicos do Portal Nacional de Contratações Públicas (PNCP), agregados pela base aberta do Atlas Licitações (a mesma que alimenta atlaslicitacoes.com/plataforma/oportunidades), com fallback direto na API oficial do PNCP.

Filtros disponíveis

  • — Fim do recebimento de propostas (período + atalhos)
  • — UF e município (com autocompletar)
  • — Modalidade da licitação (Lei 14.133/2021)
  • — Sistema fonte: ComprasNet, BLL Compras, BNC…
  • — Faixa de valor estimado e ordenação
